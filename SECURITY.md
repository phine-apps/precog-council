# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Precog Council seriously. If you discover a vulnerability or security risk (especially regarding prompt injections, token handling, or arbitrary code execution), please do **NOT** open a public issue.

Instead, please report security issues via GitHub Private Vulnerability Reporting on this repository, or contact the maintainers directly.

We will acknowledge receipt within 48 hours and work with you to triage and address the issue before public disclosure.
